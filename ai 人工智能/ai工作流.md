# 什么是ai自动化工作流
ai自动化工作流指的是将AI模型以节点的方式嵌入到工作流中从而实现功能打通的一套系统，它一般具有如下特点：
1. 快速构建与部属：一般只需要简单配置和发布就能线上运行
2. 降低技术门槛：使得其它人员可以快速参与产品构建
3. 降低复杂工作的人力成本：使用工作流工具可以大幅降低某些繁琐工作中的人力成本
4. 可视化界面：只需要在节点中简单点击即可获得需要繁琐调试的结果
此外，由于大模型api的成本足够低，工作流的构建成本也在不断减低

它能做什么：
1. 客服系统、机器人
2. 智能邮件助手
3. 内容生成
4. 客户关系分析
5. 数据分析
工作流特别适合解决某些重复性问题

# 工作流部署方式
1. 官方云托管：直接将工作流部署到官方的云服务器上，一键上手使用，但需要按需订阅
2. 云服务器自托管：使用一些云服务器，如AWS等云托管，仍然需要一定成本
3. 本地部署：只有有服务器即可，但缺点是没有公网IP就无法基于远程web服务触发

使用Docker进行环境隔离：
1. 进入Docker Desktop官网，下载对应版本
2. 下载完成后按照提示下载WSL2.0
3. 进入Docker hub或images界面拉取n8n镜像
4. 配置端口号和本地文件路径等

使用npm安装：
1. 确保本地node和npm环境
2. 全局安装n8n：npm install -g n8n
3. 终端输入n8n运行应用，输入o进入应用

打开n8n后只需简单配置即可进入首页

# 进入工作流构建
工作流的构建包括以下几个层面的内容：
1. 认识界面、节点
2. 连接外部api
3. 数据处理、传输等

## 触发节点
触发节点决定工作流的触发环境，自动执行的条件

触发条件包括：
- 点击触发
- 时间间隔触发
- weburl  hook触发
- 表单提交触发
- 被其他工作流调用时触发
- ai对话输入触发
- 外部应用触发

## ai智能体
ai智能体部分即整个工作流的主体部分，ai智能体提供了一系列服务的“中间过程”

当接收到触发节点的触发信息后，ai智能体就开始工作，根据接入大模型提供的服务进行数据处理

在ai智能体中可以选择要使用的大模型、存储工具等

## 应用
应用层决定了我们到底要用ai做什么，输出的结果是什么
